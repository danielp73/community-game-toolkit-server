Install the Toolkit

Set up the Community Game Development Toolkit in a new Unity project.

Download the installer script
  1. Create a new Unity project.
  2. Choose the Universal 3D template (the default choice).
  3. Download the installer script above.
  4. Drag the script into your Unity project.
  5. Select Game-Toolkit → Install Toolkit from the Unity menu.
